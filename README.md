# Farm Project – PAZ1a

This repository contains an assignment developed as part of the course **PAZ1a** at the Pavol Jozef Šafárik University in Košice (UPJŠ).

The project implements a flowerbed farm simulation utilizing object-oriented programming in Java and the JPAZ2 library (mouse event handling, array management, and custom graphical visualization).
